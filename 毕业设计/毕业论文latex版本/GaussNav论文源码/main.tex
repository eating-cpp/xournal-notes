\begin{abstract}
在具身视觉领域，实例图像目标导航（Instance ImageGoal Navigation, IIN）要求智能体在未知环境中定位目标图像所描绘的特定物体。IIN任务的核心挑战在于，智能体需要在不同视角下识别目标物体，同时忽略潜在的干扰物。现有的基于地图的导航方法通常使用鸟瞰图（Bird's Eye View, BEV）地图，这类地图缺乏场景的精细纹理表示。因此，尽管BEV地图在语义级视觉导航任务中表现出色，但在实例级任务中却难以胜任。

为此，我们提出了一种全新的IIN任务框架——面向视觉导航的3D高斯泼溅技术（Gaussian Splatting for Visual Navigation, GaussNav），该框架基于3D高斯泼溅（3D Gaussian Splatting, 3DGS）构建了一种新颖的地图表示形式。GaussNav框架使智能体能够同时记忆场景的几何信息和语义信息，并保留物体的纹理特征。

通过将相似物体的渲染结果与目标图像进行匹配，智能体可以准确地识别、定位并导航至指定物体。我们的GaussNav框架实现了显著的性能提升，在极具挑战性的Habitat-Matterport 3D（HM3D）数据集上，路径长度加权成功率（Success weighted by Path Length, SPL）从0.347提升至0.578。源代码已公开发布于：\url{https://github.com/XiaohanLei/GaussNav}。
\end{abstract}
